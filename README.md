# Connect 4 -tekoäly

Minimax algoritmi jota voi käyttää graafisesti valmiin tekoälyalustan kautta.

## Vaatimukset

- Python 3.11 tai uudempi
- Poetry

## Asennus

Kloonaa projekti ja asenna riippuvuudet projektin juuresta:

```bash
poetry install
```

## Tekoälyalusta

Asenna tekoälyalusta näiden ohjeiden mukaan ja aloita pelaaminen: 
[Tekoälyalusta](https://algolabra-hy.github.io/aiplatform-fi)

Voit tehdä siirron vuorossa olevalla värillä klikkaamalla saraketta pelilaudalla. Jos haluat että tekoäly tekee seuraavan siirron niin paina PLAY!.
Jos haluat pelata punaisella tekoälyä vastaan kokonaisen pelin, niin laita ruksi kohtaan "Send PLAY after move", jolloin tekoäly tekee siirron automaattisesti oman siirtosi jälkeen.
Peli pelaa vakiona kuuden siirron syvyydellä ja 0,2 sekuntin aikarajalla.
